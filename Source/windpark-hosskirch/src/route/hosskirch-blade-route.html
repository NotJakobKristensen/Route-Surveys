Running without the graphics card

This browser is drawing the 3D view in software, so it will be slow. Hardware acceleration is switched off or blocked here. In Chrome or Edge: Settings → System → turn on Use graphics acceleration when available and restart the browser. In Firefox: Settings → General → Performance.
