# Windpark Hoßkirch

The six Vestas V172-7.2 MW of Windpark Hoßkirch in the Wagenhart forest (Baden-Württemberg) in 3D: exact turbine positions, terrain, forest, roads and buildings from official open data.

## ⬇ [Download the HTML file](https://github.com/NotJakobKristensen/Route-Surveys/raw/main/Windpark_Hosskirch/windpark-hosskirch.html)

[`windpark-hosskirch.html`](windpark-hosskirch.html) holds the whole page in one file — all data inside, no Claude branding. Save it, then double-click it: it opens in any
browser on your computer and can be emailed or put on a USB stick. It runs exactly as in the browser link.

- If the download link shows text instead of saving the file: right-click the link → **Save link as…**, or open [`windpark-hosskirch.html`](windpark-hosskirch.html) and
  click **Download raw file** (⬇, top right of the file view).
- Internet is still needed for the 3D engine (three.js) and the fonts.
